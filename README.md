## 📖 Module Index & Topics

### 🔹 Lesson 1: Linux Distributions
* Upstream vs. Downstream open-source flow
* The RHEL development pipeline: Community ➔ Fedora ➔ CentOS Stream ➔ RHEL
* Enterprise stability and support models

### 🔹 Lesson 2: Introduction to the Shell
* Role of the Bash shell as an interpreter between user and kernel
* Command syntax structure: `command [options] [arguments]`
* Standard input/output redirection and pipeline chaining (`|`)

### 🔹 Lesson 3: Documentation Systems
* Navigating manual pages (`man`) and understanding section numbers
* Keyword lookup with `apropos` and `whatis`
* Interactive documentation nodes via `info` and `pinfo`

### 🔹 Lesson 4: Command Line Assistant
* Overview of AI-assisted terminal guidance in RHEL
* Natural language translation to system administration tasks
* Operation modes: Connected vs. Offline (Podman containers)

### 🔹 Lesson 5: Linux Directories Explained
* The single-root concept (`/`) in Linux vs. drive letters
* File System Hierarchy Standard (FHS) overview
* Core directory purposes: `/bin`, `/etc`, `/var`, `/home`, `/proc`, and `/usr`
